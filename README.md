# Afraa Restaurant website

Static site (HTML, CSS, JS). No build step.

- Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages: Settings > Pages > deploy from branch, root folder).
- Menu items and prices live in `menu-data.js`. Photos are in `images/`.
- Contact form: set `data-endpoint` on the form in `index.html` (for example `https://formsubmit.co/ajax/you@example.com`) to receive messages.
