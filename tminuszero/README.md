# T Minus Zero AI Advisory website

Static site (HTML, CSS, JS). No build step. Open `index.html` in a browser or deploy this folder to any static host.

- Copy lives in `index.html`; styles in `styles.css`; countdown console, starfield and form logic in `script.js`.
- Contact form: set `data-endpoint` on `#contact-form` (for example a Formspree URL) to receive messages.
- Client list: the "Mission log" section in `index.html`. Confirm each client has approved being listed before going live.
